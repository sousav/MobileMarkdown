## Full Description

### Google Play Store / Apple App Store

MobileMarkdown opens .md files and renders them beautifully. That's it.

Tap a markdown file on your phone and see it rendered with proper formatting — headings, code blocks with syntax highlighting, tables, images, links, and more. No editor. No note-taking platform. No subscription. Just a viewer.

FEATURES:
- Open .md files from your file manager, share sheet, or the in-app file picker
- Beautiful rendering of CommonMark and GitHub Flavored Markdown (GFM)
- Syntax highlighting for 30+ programming languages
- Tables, checkboxes, images, blockquotes, and horizontal rules
- Light, Dark, and System theme modes
- Recent files list for quick access
- Tappable links open in your default browser

WHAT THIS APP IS NOT:
- Not an editor — use your favorite text editor for that
- Not a note-taking app — there are plenty of those already
- Not a subscription service — it's free, forever

PRIVACY:
- No accounts required
- No analytics or tracking
- No ads
- No internet permission (works fully offline)
- Your files stay on your device

SUPPORTED FILE TYPES:
- .md (Markdown)
- .markdown
- .txt (rendered as markdown)
